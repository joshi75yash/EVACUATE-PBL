# EVACUATE-PBL
### Intelligent Emergency Route & Crowd Management System

## About the Project
Our project helps manage people during emergencies and makes evacuation easier and more organized.

## My Contribution
My main contribution to this project is **Queue and Priority Queue**.

### 1. Queue
A queue follows the **FIFO (First In, First Out)** rule, which means the person who comes first is served first.

**Use:** It helps manage people or requests in the order they arrive.

### 2. Priority Queue
A priority queue processes elements according to their priority instead of their arrival order.

**Use:** It helps process urgent requests before less urgent ones during an emergency.

### Files
- `Queue.h` – Contains the declarations of queue functions.
- `Queue.cpp` – Contains the implementation of queue functions.
- `README.md` – Explains the project.

## Conclusion
Queue and Priority Queue help us manage requests in an organized way. A normal queue follows arrival order, while a priority queue gives preference to higher-priority tasks.
