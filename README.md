# EVACUATE-PBL
During an emergency, a route that is safe right now might not stay safe five minutes later. Corridors get blocked, exits jam up, and when everyone rushes toward the same door, new hazards form fast. EVACUATE is built to adapt in real time instead of giving people a fixed set of instructions and hoping for the best.

Under the hood, the system views a building or evacuation zone as a connected network. Smart routing algorithms constantly re-check paths as conditions change, while queues keep track of crowd flow to prevent bottlenecks. Users can test real-world emergencies by dropping hazards or blocking hallways on an interactive map, forcing the system to instantly find alternative paths. We specifically test EVACUATE against worst-case scenarios—like sudden blockages, extreme overcrowding, and complete zone cut-offs—to ensure it reliably saves lives when things go wrong.
